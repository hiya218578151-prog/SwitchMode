# Rail Rush — Keypad Runner

A from-scratch Android endless runner inspired by the documented three-lane runner mechanics in `הסבר משחק.docx`.

Designed for physical-key navigation and small screens. Original code, visuals, characters, boards, and branding are used instead of copying proprietary game assets.

## Controls
- D-pad / 4 / 6: change lane
- Up / 2: jump
- Down / 8: roll
- OK / 5: confirm / start / activate board
- 7: activate hoverboard
- Back / 0: pause or return

Minimum Android version: 4.4.2 (API 19).
